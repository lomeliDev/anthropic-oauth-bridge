**OpenAI-compatible proxy over the Anthropic Messages API — API keys or AWS Bedrock, multi-account, quota, thinking, web search, PDFs.**

</div>

> **v1.0 (branch `dev`) — what changed and why.** The previous version authenticated with Claude Pro/Max
> subscription OAuth by impersonating Claude Code. Since **Feb 19, 2026** Anthropic's terms prohibit subscription
> OAuth tokens in third-party tools, and since **Apr 4, 2026** it is enforced server-side (OpenClaw/OpenCode were
> cut off; OpenCode removed its OAuth code). This rewrite drops OAuth and the cloaking layer entirely and uses
> **Anthropic Console API keys** (pay-as-you-go) or **AWS Bedrock**. Same OpenAI-compatible surface, more features.
> If you want Claude on a subscription-style quota, use Claude Code directly, or Claude via Google's Antigravity
> platform (see [antigravity-bridge](https://github.com/lomeliDev/antigravity-bridge)).

## ⚡ TL;DR

```bash
git clone -b dev https://github.com/lomeliDev/anthropic-oauth-bridge.git anthropic-bridge
cd anthropic-bridge
./install.sh          # venv, .env (API key or Bedrock), keys, daemon, smoke test
```

Then point any OpenAI client at `http://127.0.0.1:64173/v1` with the client key the installer printed. Docs: `http://127.0.0.1:64173/docs`.

## ✨ Features

| | |
|---|---|
| **OpenAI chat API** | `/v1/chat/completions` (normal + streaming), `/v1/models` with metadata, `/v1/usage` |
| **Anthropic passthrough** | `/v1/messages` — native format, same multi-account layer |
| **Thinking** | `reasoning_effort: low\|medium\|high` → extended thinking + `output_config.effort`; thinking returned as `reasoning_content` (message and stream deltas); thinking blocks replayed automatically on multi-turn tool use |
| **Tools** | function calling (schemas sanitized for Claude, orphan pairs repaired, parallel calls), `response_format` json_object/json_schema |
| **Server tools** | `web_search` (Google-grade grounding by Anthropic, with `citations`), `code_execution` (sandbox; code + output in markdown) |
| **Multimodal** | images (URL/data-URI), **PDF and text documents** as native `document` blocks |
| **Prompt caching** | `cache_control` on the system prompt by default; cache tokens reported in `usage` |
| **Multi-account** | `accounts.json`: each client key → its own Anthropic key or Bedrock region/profile; `/admin/*` to manage, `?quota=1` to see all |
| **Quota** | `/v1/quota` from `anthropic-ratelimit-*` headers (requests/tokens remaining + reset) |
| **Ops** | `.env` loaded by the server, `BRIDGE_DEBUG=1` tracebacks + upstream log, `/health` never 500s, systemd/launchd installer, Swagger UI, SSRF-guarded URL fetching, constant-time key checks |

## 🚀 Install

```bash
./install.sh
```

The installer asks for: backend (Anthropic API key or Bedrock region/profile), listen host/port, a client key and an
admin key (generated by default), then writes `.env`, installs a **systemd** (Linux) or **launchd** (macOS) service and
runs a smoke test (`/health`, `/v1/models`, `/v1/chat/completions`, `/v1/quota`, `/docs`). Re-running it keeps your `.env` values.

Manual run: `.venv/bin/python3 server.py --host 127.0.0.1 --port 64173`

### Multi-account

```bash
cp accounts.example.json accounts.json   # edit: one entry per client key
# or at runtime:
curl -X POST http://127.0.0.1:64173/admin/accounts -H "Authorization: Bearer $ADMIN_KEY" -H 'Content-Type: application/json' \
  -d '{"api_key":"sk-team-b","label":"Team B","backend":"anthropic","anthropic_key":"sk-ant-api03-..."}'
curl -H "Authorization: Bearer $ADMIN_KEY" "http://127.0.0.1:64173/admin/accounts?quota=1" | jq
```

### Bedrock

`BRIDGE_BACKEND=bedrock`, `AWS_REGION=mx-central-1` (and `AWS_PROFILE` if not the default chain); `pip install boto3`.
Model ids map through `BEDROCK_MODEL_MAP` / `BEDROCK_MODEL_<ID>` env overrides (inference profile ARNs work).

## 🧪 Quick tests

```bash
BASE=http://127.0.0.1:64173; KEY=sk-bridge-...
curl -s $BASE/v1/chat/completions -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"model":"claude-sonnet-4-6","reasoning_effort":"medium","messages":[{"role":"user","content":"why is the sky blue?"}]}' | jq '.choices[0].message'
curl -s $BASE/v1/chat/completions -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"model":"claude-sonnet-4-6","web_search":true,"messages":[{"role":"user","content":"latest opencode release?"}]}' | jq '{c:.choices[0].message.content,cites:.choices[0].message.citations}'
curl -s $BASE/v1/quota -H "Authorization: Bearer $KEY" | jq
```

## 🔒 Security (short version)

Set a client key **and** an admin key (the installer generates both), bind `127.0.0.1` or use a tailnet/TLS proxy,
keep `BRIDGE_DEBUG=0`. Client-supplied URLs are SSRF-guarded. `.env` and `accounts.json` hold API keys — mode 600.
